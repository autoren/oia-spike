# Frozen v0.2.0 instrument sources

This directory is a byte-for-byte source snapshot for every path listed by the unchanged audit-002 `instrument_source_provenance.json`.

Historical path resolution is:

```text
historical/v0.2.0/instrument_sources/<recorded path>
```

The snapshot authenticates the implementation that produced the original prospective audit. It is historical evidence only. The corrected v0.2.1 implementation lives at the normal package paths and has a separate current-source manifest.
