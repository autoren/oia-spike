# Tycho target-kernel preflight R2a

R2a packages—but does not execute—the exact credential-free target-kernel
preflight implied by the local Sandlock R1 pass. The output is an untracked,
deterministic offline ZIP suitable for attachment to a later internet-disabled
target notebook.

R2a cannot establish target-kernel support. It authorizes no upload, notebook
run, credential use, model/GPU/ARC/OIA execution, submission, or hidden access.
